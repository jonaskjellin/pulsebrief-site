11-Year-Old Microsoft-Signed UEFI Shims Let Attackers Bypass Secure Boot on Nearly Any System


Jul 14, 12:46


ESET researchers discovered 11 outdated Linux UEFI shim bootloaders — some over a decade old, all signed by Microsoft's UEFI CA 2011 certificate — that remain trusted by UEFI firmware and can be used to bypass Secure Boot on virtually any UEFI-based machine regardless of OS. An attacker with one of these vulnerable shims can execute untrusted code during the boot process, enabling deployment of UEFI bootkits that survive OS reinstalls. The shims are at version 0.9 or earlier and the Microsoft-signed certificates have not been revoked.


Signed bootloader artifacts that bypass Secure Boot on nearly any UEFI system are a critical firmware-level persistence threat — relevant for any organization that treats Secure Boot as a meaningful security control.
