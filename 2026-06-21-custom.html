Linux Eliminates strncpy API After Six Years and 360 Patches — Major Kernel Security Hardening Milestone


Jun 20, 24:00


Linux 7.2 has fully removed the strncpy API from the kernel after a six-year effort spanning 360 patches, eliminating a class of memory safety bugs that has contributed to vulnerabilities across decades of C code. The removal is one of the most significant memory safety improvements in Linux kernel history and sets a precedent for how legacy unsafe APIs can be systematically excised from large codebases. It also signals the kernel community's increasing alignment with memory-safe programming principles without a full language rewrite.


Elimination of a foundational unsafe API from the Linux kernel is a landmark security hardening event relevant for any organization running Linux infrastructure or contributing to kernel-adjacent software
