CISA adds VMware vCenter, Cisco Expressway, SAP NetWeaver and Apache Roller flaws to its exploited-vulnerabilities list

GnuPG warns of critical GPGME flaw: a malicious OpenPGP key can expose application data


Nov 21, 09:32


The GnuPG project says a malicious OpenPGP key with an unusually long user ID can trigger a critical memory bug in GPGME, the library most programs use to work with GnuPG. The flaw (CVE-2026-129975) could be used to steal data from affected applications. It affects all software using GPGME before version 2.3.0, and fixed versions are out. The GnuPG announcement was also the subject of a Hacker News thread titled 'RCE in Gnupg' (166 points).


GPGME sits underneath many mail and signing tools, so check which of your applications bundle it and update to 2.3.0 or later.

Detail emerges on the AI-agent zero-day: MONAI Label flaw gave root on a university server (vendor research)


Nov 21, 12:03


Amazon Threat Intelligence says suspected China-linked attackers used autonomous AI agents to find a previously unknown flaw in MONAI Label, an open-source medical imaging server. The bug lets an unauthenticated attacker write files outside the server's storage folder, and it affects MONAI Label 0.8.5 and earlier in the default setup. The attackers gained root on a university server. The findings come from Amazon's own research.


This confirms the exposed product and the exploit class for the first documented case of AI agents finding and exploiting a zero-day, so anyone running MONAI Label has a concrete patch target.
