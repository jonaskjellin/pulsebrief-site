Unpatchable 'usbliter8' BootROM Exploit Hits Apple A12 and A13 — Hundreds of Millions of iPhones Permanently Vulnerable


Jun 19, 24:00


Paradigm Shift researchers published usbliter8, a working exploit achieving arbitrary code execution inside the SecureROM of Apple A12 and A13 chips — covering iPhone XS/XR through iPhone 11 series. Because the vulnerability resides in silicon-burned code, no software update can remediate it; affected devices carry this flaw permanently. The attack requires physical USB access, so it is not remotely exploitable, but enables full boot-chain compromise, persistent implants surviving factory resets, and forensic bypass on any device that falls into an attacker's hands.


Permanent, hardware-rooted vulnerability in hundreds of millions of deployed iPhones requires immediate device lifecycle planning for any high-security environment — physical device security controls become critical
