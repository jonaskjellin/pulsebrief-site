Tailscale SSH Flaw Lets a Compromised Device Reach Root on Other Servers


Oct 25, 17:44


A security researcher has disclosed that a single hacked device on a Tailscale network can be used to gain root access on other servers it can reach, provided Tailscale SSH is configured to allow port forwarding. The attack requires an attacker who already controls one permitted device — a realistic post-compromise scenario in many enterprise environments. The vulnerability remains unpatched, making it immediately relevant for any organization using Tailscale SSH for internal access.


Tailscale is widely deployed as a zero-trust overlay network; an unpatched lateral movement path from any compromised node to root on other servers is a critical architectural risk.
