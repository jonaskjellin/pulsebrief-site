Cyber Security


Microsoft discloses Entra Connect Health breach: attackers pulled admin emails and tenant configuration data


Nov 21, 19:01


Microsoft warned customers that attackers exploited a flaw in its Entra Connect Health service to read administrator and technical contact email addresses and tenant configuration data. A customer notice shared on Reddit describes read-only access to those records, not access to inboxes or messages. Microsoft fixed the cloud-side flaw on November 19. The details come from Microsoft's own notice, and the number of affected tenants has not been given.


Admin contact emails and tenant configuration data are useful for targeted phishing and reconnaissance against identity infrastructure, so expect follow-on social engineering aimed at your admins.


Sources: BleepingComputer · Cybersecurity News

Upload2Shell: patched Ghostscript flaw gives remote code execution through ordinary file uploads (vendor research)


Nov 21, 19:29


Security firm pwn.ai showed that a crafted file can escape Ghostscript's sandbox and run commands on the server that processes it. The flaw is CVE-2026-125396 and affects Ghostscript releases before 10.08.0. The researchers demonstrated it against WordPress, Roundcube webmail and Linux print servers. Applications often invoke Ghostscript indirectly to convert uploaded PDFs, PostScript and images. A fix is available, and no exploitation in the wild has been reported.


Ghostscript is buried inside many upload-handling pipelines, so you may be exposed without knowing it. Check server images and containers for versions before 10.08.0.


Sources: The Hacker News · Cybersecurity News · pwn.ai (vendor research)


AI & Machine Learning


OpenRouter drops three AI inference providers after months of prompt theft found by Dragos


Nov 22, 03:14


Dragos researchers found that attackers had stolen data from inside three AI inference providers for months, and none of the providers knew until they were told. Some of the stolen requests were flagged Zero Data Retention. OpenRouter, the gateway that routes requests to a pool of providers, removed the three and revoked ZDR eligibility for 125 endpoints. In its November 22 incident notice it says it notified all potentially affected customers. The notice is OpenRouter's own account, and the Dragos findings are vendor research.


It shows that a 'zero retention' label from a downstream AI provider is not a guarantee, so anything sent through third-party inference routes should be treated as exposed.


Sources: The Hacker News · Cybersecurity News · OpenRouter (vendor notice)
