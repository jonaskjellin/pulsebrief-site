TONTOU Attack Bypasses All Spectre v2 Mitigations on Intel and AMD — Leaks Linux Password Hashes


Aug 6, 16:17


MIT CSAIL researchers disclosed INTERRUPT INJECTION (branded TONTOU), a technique that times a hardware interrupt to land in the gap between a CPU sanitizing its branch predictor and the kernel using it — re-poisoning the predictor after all current Spectre v2 defenses have run. On an AMD Zen 2 machine running Linux 6.14 with every default mitigation enabled, the attack successfully leaked Linux password hashes. The vulnerability affects both Intel and AMD processors and bypasses mitigations that have been in place for years.


A published bypass of all deployed Spectre v2 mitigations on both major x86 CPU families reopens a hardware attack surface that organizations considered closed — assess exposure on Linux workloads handling sensitive credentials.
