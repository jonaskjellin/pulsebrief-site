AI Coding Agents Hijacked via Malicious AGENTS.md File in Downloads Folder


Oct 25, 15:49


Researchers discovered a malicious AGENTS.md markdown instruction file placed in a customer's Downloads folder that successfully tricked an AI coding agent into installing a rogue npm package — exploiting the convention where coding agents automatically ingest instruction files from the local filesystem. The attack requires no code execution or privilege escalation; placing a crafted markdown file in a location the agent reads is sufficient to redirect its behavior. The technique works against any AI coding agent that trusts local instruction files without verification, including widely deployed tools like Claude Code, Cursor, and Copilot Workspace.


A trivially simple attack vector — a text file in Downloads — that hijacks AI coding agents is a critical finding for any team deploying agentic coding tools in development environments.


Sources: BleepingComputer
