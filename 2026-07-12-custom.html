jscrambler 8.14.0 npm Package Compromised — Installs Rust Infostealer on All Platforms

The popular jscrambler npm package was backdoored in version 8.14.0, with a preinstall hook that drops and executes a native Rust infostealer binary targeting Windows, macOS, and Linux. A compromised install-time hook in a widely used JavaScript toolchain package is a classic supply chain attack — any team using jscrambler must audit install logs and assume credential exposure.
