15-Year-Old NGINX Vulnerability Enables Worker Crashes and Potential RCE — Patch to 1.30.4 Immediately


Jul 19, 20:42


CVE-2026-42533, a heap buffer overflow in NGINX's script engine silently exploitable since March 2011, allows remote unauthenticated attackers to crash worker processes and potentially achieve remote code execution via crafted HTTP requests. Fixes are available in nginx 1.30.4 (stable), 1.31.3 (mainline), and NGINX Plus 37.0.3.1 — released July 15. Given NGINX's position as one of the world's most deployed web servers, the attack surface is enormous and unpatched systems should be treated as urgent.


A 15-year-old critical RCE in the world's most widely deployed web server is a mass-exposure emergency — every unpatched NGINX instance is at risk.
