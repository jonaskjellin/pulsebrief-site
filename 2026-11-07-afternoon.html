Claude Code's 'Don't Ask Again' Feature Leaks 2,539 Secrets Across 1,994 Public GitHub Repos


Nov 7, 06:44


When developers select 'Yes, and don't ask again' in Claude Code, the tool saves the approved command verbatim — including any passwords or API keys embedded in it — to a project settings file that often ends up committed to public GitHub repositories. Apiiro researchers found 2,539 distinct secrets across 1,994 public repositories, affecting 63 organizations, mostly software companies. Any developer who has used this workflow and pushed their project to a public repo should audit their settings files and rotate exposed credentials immediately.


A widely-used AI coding assistant is silently exfiltrating secrets to public GitHub through a routine UX interaction — this is an active, ongoing credential exposure affecting thousands of repositories right now.
