Ghostcommit: PNG-Embedded Prompt Injection Bypasses AI Code Reviewers, Exfiltrates Repo Secrets


Jul 11, 24:00


Researchers demonstrated 'Ghostcommit,' a technique that hides prompt injection instructions inside PNG image files committed to repositories. AI code review tools CodeRabbit and Bugbot never open image files, so the injection goes undetected — then convinces a coding agent to read the repo's .env file and encode every secret into the codebase as a list of numbers. The attack requires no special privileges and exploits a fundamental blind spot in how AI agents handle non-text file types.


Any team using AI coding agents for code review or automation has a new, undefended exfiltration path that bypasses current tooling — secrets are at risk from a committed image file.


Sources: BleepingComputer

Jul 11, 24:00


Wired reports that an AI system identified the GhostLock privilege escalation vulnerability in the Linux kernel's io_uring subsystem — a flaw that had existed undetected for approximately 15 years across all major Linux distributions. Patch availability is being tracked by the Linux security community.


A 15-year-old local privilege escalation in every Linux distribution is a foundational risk for any organization running Linux servers, containers, or cloud workloads — patch status must be tracked.
