GhostLock: 15-Year-Old Linux Kernel Flaw Grants Any Local User Full Root — Affects Every Major Distro Since 2011


Jul 8, 24:00


Researchers disclosed CVE-2026-43499 ('GhostLock'), a privilege escalation flaw in the Linux kernel's real-time mutex subsystem introduced in kernel 2.6.39 in 2011 and present in every mainstream Linux distribution since. Any logged-in user can achieve full root control with no special permissions, unusual settings, or network access required. The flaw also enables container escape, making it critical for cloud and containerized workloads. Patches are rolling out but distribution of fixes across the ecosystem will take time.


A no-prerequisites local root exploit shipping by default in every Linux distro for 15 years is a patch emergency for any organization running Linux infrastructure, cloud workloads, or containerized environments.
