HTTP2Shell / Brotli Critical Flaw Triggers Emergency Patches Across Node.js, .NET, PHP, and Cloudflare WAF


Oct 26, 13:18


A critical buffer overflow in the Brotli C decoder library — tracked as HTTP2Shell / Node2Shell / CVE-2026-111497 — has triggered a cascade of emergency patches across Node.js, Microsoft .NET (versions 8 through 11), PHP Windows builds, and a Cloudflare WAF ruleset update. Microsoft's out-of-band .NET release and Cloudflare's emergency WAF update signal the industry is treating this as a critical-severity event requiring immediate action.


Four sources covering the same emergency patch wave across Microsoft, Node.js, PHP, and Cloudflare simultaneously — this is a cross-stack vulnerability requiring dependency chain review for virtually every modern application.
