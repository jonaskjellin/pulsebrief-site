Microsoft's Agent Framework PyPI Package Poisoned With Credential Stealer


Nov 18, 06:45


Attackers compromised Microsoft's agent-framework package on PyPI. Versions 1.26.1 and 1.26.2 were published 33 minutes apart on November 17 and run a stealer every time Python starts. Java4Shell (CVE-2026-114938): CISA Urges Immediate Patching of Java Flaw Hitting Jira, Jenkins, Keycloak


Nov 18, 07:43


Calif disclosed Java4Shell, an out-of-bounds write (CVSS 8.1) in Oracle Java 17.0.6 and later. It can lead to DoS or pre-auth remote code execution. The vulnerable code runs only on x86-64 Intel and AMD chips with AVX-512 VBMI. Calif demonstrated RCE in Jira, Jenkins and Keycloak, and CISA is urging immediate patching. VulnCheck cautions that real-world RCE requires per-target work.


The flaw sits in the Java runtime beneath widely deployed enterprise apps, and CISA's warning makes this a patch-now item despite the exploitation caveats.


Sources: The Hacker News · The Hacker News (CISA) · SecurityWeek
