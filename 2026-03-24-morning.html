Oracle Releases Emergency Patch for Critical Identity Manager RCE Vulnerability


Mar 23, 05:34


Oracle issued an out-of-band security update for CVE-2026-21992, a critical vulnerability in Identity Manager and Web Services Manager that allows unauthenticated remote code execution. The flaw has a CVSS score of 9.8 and may have been exploited in the wild. Attackers can execute arbitrary code without authentication if Oracle's Identity or Web Services Managers are exposed to the web.

Starlette 1.0 Released with Breaking Changes to Startup/Shutdown Handling


Mar 22, 23:57


Starlette, the ASGI framework underlying FastAPI, has reached its 1.0 milestone with several breaking changes including a new lifespan mechanism replacing on_startup and on_shutdown parameters. The framework now uses async context managers for managing application lifecycle events. The release marks a significant stability milestone for the framework that has powered FastAPI's success while maintaining relatively low brand recognition.
